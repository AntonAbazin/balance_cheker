# Balance Checker

Сервис для отслеживания баланса крипто-кошельков (Ethereum, BSC, TRON) с уведомлением
в Telegram при изменении баланса.

## Возможности

- Веб-интерфейс: добавление кошелька (имя, блокчейн, адрес), список, ручная проверка, удаление.
  Валюту указывать не нужно — для каждого кошелька автоматически проверяются
  баланс USDT и баланс нативной монеты блокчейна (ETH/BNB/TRX, для газа).
- Автоматическая фоновая проверка балансов по расписанию (интервал задаётся в `.env`).
- Уведомления в Telegram — только по изменению баланса USDT. При изменении
  USDT-баланса любого кошелька в сообщение попадают балансы USDT всех кошельков
  (по всем сетям) и итоговая сумма. Баланс нативной монеты отслеживается и
  сохраняется, но уведомлений по нему нет.
- Список кошельков отсортирован по имени.
- Один пользователь, без авторизации в веб-интерфейсе.

## Требования

Node.js >= 22.5.0 (используется встроенный `node:sqlite`, нативных зависимостей нет).

## Установка

```bash
npm install
cp .env.example .env
```

Заполните `.env`:

1. **ETHERSCAN_API_KEY** — бесплатный ключ на https://etherscan.io/myapikey.
   Один ключ покрывает и Ethereum, и BSC (Etherscan API V2, multichain).
2. **TRONGRID_API_KEY** — необязателен (публичный доступ работает и без ключа,
   но с более строгими лимитами). Получить: https://www.trongrid.io/.
3. **TELEGRAM_BOT_TOKEN** — создать бота через [@BotFather](https://t.me/BotFather), скопировать токен.
4. **TELEGRAM_CHAT_ID** — свой chat_id: написать боту `/start`, затем открыть
   `https://api.telegram.org/bot<TOKEN>/getUpdates` и найти `chat.id`,
   либо узнать через [@userinfobot](https://t.me/userinfobot).
5. **TELEGRAM_PROXY_URL** — если Telegram Bot API недоступен напрямую (блокировки
   у провайдера). Не обязателен. Поддерживаются HTTP/HTTPS и SOCKS4/SOCKS5:
   `socks5://user:pass@host:port`, `http://user:pass@host:port` и т.п.
   Прокси используется только для запросов к Telegram — на Etherscan/TronGrid
   не влияет.
6. **CHECK_INTERVAL_MINUTES** — как часто проверять балансы (по умолчанию 5).

## Запуск

```bash
npm start
```

Веб-интерфейс: http://localhost:3000

## Как это работает

- При добавлении кошелька сразу выполняется первая проверка — она сохраняется
  как база для сравнения, без уведомления (иначе телеграм присылал бы сообщение
  на каждое добавление кошелька).
- Дальше баланс проверяется фоново каждые `CHECK_INTERVAL_MINUTES` минут для всех
  кошельков сразу, плюс есть кнопка «Проверить» для ручной проверки одного кошелька.
- Уведомление в Telegram отправляется только если новый баланс USDT-кошелька
  отличается от последнего сохранённого; для остальных валют сообщение не шлётся,
  хотя баланс всё равно обновляется в базе.
- Данные хранятся в SQLite (`data/balance_checker.db`).

## Запуск через Docker

```bash
docker compose up -d --build
```

Веб-интерфейс будет на `http://localhost:8006` (наружу — 8006, внутри контейнера
приложение слушает `PORT` из `.env`, по умолчанию 3000; при желании поменять
внешний порт — правьте `ports` в `docker-compose.yml`).

- `.env` должен быть заполнен заранее (тем же файлом, что и для запуска без Docker) — прокидывается в контейнер через `env_file`.
- SQLite-файл хранится в `./data` на хосте (bind mount) — переживает пересборку и перезапуск контейнера.
- Логи: `docker compose logs -f`. Остановить: `docker compose down`.

## Известные ограничения MVP

- Один Telegram-чат для всех уведомлений (без многопользовательской авторизации).
- Баланс токена хранится как число с плавающей точкой — для целей уведомлений
  этого достаточно, но не годится для точных бухгалтерских расчётов.
- Отслеживаются только USDT и нативная монета блокчейна; произвольные токены
  не поддерживаются.
- Курсы валют не учитываются — сервис сравнивает баланс в нативных единицах
  токена, не в фиате.
